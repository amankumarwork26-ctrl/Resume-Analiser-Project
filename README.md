# AI Resume Analyzer

This is a simple AI-powered Resume Analyzer that helps users get quick feedback on their resumes. Just upload your resume, and the application analyzes it using AI to provide useful suggestions for improving content, structure, and ATS compatibility.

I built this project to learn how AI APIs work with full-stack web development while creating something that can be useful for students and job seekers.

---

## Features

- Upload resumes in PDF format
- AI-generated resume analysis
- Suggestions to improve resume quality
- ATS-friendly feedback
- Clean and responsive user interface
- Secure backend for API requests

## Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/AI-Resume-Analyzer.git
```

Go to the project folder:

```bash
cd AI-Resume-Analyzer
```

Install the required packages:

```bash
npm install
```

Create a `.env` file and add your API key:

```env
API_KEY=YOUR_OPENROUTER_API_KEY
PORT=3000
```

Start the server:

```bash
npm start
```

Now open your browser and visit:

```
http://localhost:3000
```
